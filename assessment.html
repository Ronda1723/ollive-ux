Root cause
The system prompt instructs the agent to "be helpful and specific about clinic logistics" but does not restrict operational facts to grounded sources. When the KB lacks an answer, the model states ungrounded specifics. All 6 cases follow this pattern.
Suggested fix system prompt · v12
Add a grounding rule for operational facts; route unknowns to a safe fallback.
## Clinic information
- Be helpful and specific about clinic logistics.
+ Only state addresses, hours, prices or insurance details that
+ appear in CLINIC_INFO or a tool result. If not found, say you
+ will text a link with the details — never guess specifics.
